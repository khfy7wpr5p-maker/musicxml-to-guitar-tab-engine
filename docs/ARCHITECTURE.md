# Architecture boundaries

`seslitab-tab-ocr-engine` is an independent service.

It must not:

- import code from `seslitab-guitar-reader`;
- read or modify Audiveris `.omr` artifacts;
- read or modify MusicXML generated by another service;
- share temporary directories, databases, or persistent disks with SesliTab;
- access SesliTab HTML or user-interface files.

Future integration is allowed only through a versioned HTTP/JSON contract.

## Planned pipeline

1. Validate PDF, PNG, or JPG input.
2. Render PDF pages to images.
3. Deskew, binarize, and remove noise.
4. Detect six-line TAB systems.
5. Detect string and measure lines.
6. Recognize fret digits in bounded image regions.
7. Assign digits to strings and group chords.
8. Validate fret range and calculate confidence.
9. Return versioned JSON with mandatory teacher review.

The current scaffold intentionally exposes no upload or OCR processing capability.
